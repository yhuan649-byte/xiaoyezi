# 晴间来信 · 手机优先的二次元角色图鉴

一个无需构建、无需安装 npm、没有外部 CDN 依赖的静态网站。可部署到 GitHub Pages，支持仓库子路径。随包包含完整源码和十张原始图片，图片名保留空格、方括号和大小写。

## 快速发布到 GitHub Pages

1. 解压本包，打开 `qingjian` 文件夹。
2. 在 GitHub 新建仓库，将该文件夹**里面的内容**上传至仓库根目录。不要只上传 ZIP，也不要再套一层 `qingjian` 文件夹。
3. 仓库首页应直接显示 `index.html`、`style.css`、`app.js`、`characters.js` 与 `assets` 文件夹。
4. 进入仓库 **Settings → Pages**。
5. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
6. Branch 选择你上传文件的分支（通常是 `main`），目录选择 **/ (root)**，保存。
7. 等待 GitHub Pages 部署完成，使用 Pages 设置页给出的 HTTPS 地址访问。典型地址为 `https://你的用户名.github.io/仓库名/`。
8. 在真实手机浏览器中打开地址，测试重力视差。不要用 GitHub 的源码预览链接代替网站地址。

不需要购买服务器、配置数据库或填写 API 密钥。若你的仓库不能启用 Pages，请检查当前账号和仓库的 Pages 可用条件。

## 文件结构

- `index.html`：页面结构、角色面板、原图鉴赏弹窗、阅读设置。
- `style.css`：颜色、布局、手机与电脑适配、夜间阅读和减少动态效果。
- `characters.js`：角色名、简介、印象标签、配色、图片清单。
- `app.js`：标签切换、收藏、分享、原图操作、感应权限与本地偏好。
- `assets/`：十张用户提供的原图，名称不变。
- `.nojekyll`：让静态文件直接发布，避免不需要的 Jekyll 处理。

图片必须放在 `assets/` 中；不要把原图放在项目根目录后期待自动识别。源码使用相对路径并编码文件名，因此空格与方括号可正常访问。

## 修改角色或添加角色

只需编辑 `characters.js` 中的 `window.CHARACTERS` 数组。每个角色包含：

```js
{
  id: 'new-character', // 唯一英文 ID，也是网址 # 后面的内容
  name: '角色名',
  subtitle: '一句话介绍',
  mood: '角色气氛',
  color: '#397dab', // 角色主题色，建议足够深以保证白色按钮文字可读
  tint: '#e7f2fb', // 浅色背景
  quote: '“角色的一句话。”',
  story: '角色手记正文。',
  tags: ['标签一', '标签二'],
  details: { '喜欢的事': '具体内容', '相遇地点': '具体内容' },
  images: [
    ['保持不变的图片文件名.png', '这幅画的说明']
  ]
}
```

修改提示：

- 将新图片放到 `assets/` 中，文件名必须与配置一致，包括大小写。
- `images` 的第一张是角色默认主图，数组顺序就是画廊顺序。
- 每个角色至少有一张图片。`id` 不要重复。
- 配置是站主维护的代码，不应直接接入不可信用户输入；当前没有上传表单或内容后台。
- 如想使用远程图片，应同时修改 `app.js` 中的 `src()` 路径函数；默认本地相对路径更适合 GitHub Pages。
- 如果以后改成其他角色，只改配置不会破坏已有布局。

## 视觉设计说明

主题是“随身携带的角色光影册”。以列车窗外的春光与角色原画作为视觉中心，周围界面保持安静。

配色：云白 `#F6FAFD`、墨蓝 `#23374B`、湖蓝 `#397DAB`、叶绿 `#56856A`、晴黄 `#F1D98A`。晴黄作为设计预留色，当前没有为了装饰强行使用。

字体：标题优先使用设备上的宋体类字体（Songti SC / Noto Serif CJK SC / SimSun）；正文使用系统黑体（PingFang SC / Microsoft YaHei 等）。不加载远程字体，字体实际外观随系统略有区别。

手机布局：品牌 → 横向角色标签 → 大幅画面 → 角色手记 → 横向画廊；底部快捷操作考虑安全区域。电脑布局：画面与角色档案并列，画廊下置。断点为 700px 与 1000px，宽屏在 1500px 以上调整画面高度。

主图是封面式裁切，完整原图在鉴赏模式显示。没有自动播放、闪烁粒子或持续滚动特效；动态仅用于主动操作反馈与轻微视差。

## 重力感应与兼容性

- 使用 `DeviceOrientationEvent`，读取设备角度来实现视觉位移，并非读取 GPS 或摄像头。
- 需要安全上下文（通常为 HTTPS）以及浏览器和设备支持。
- 一些浏览器需要用户点击后调用 `requestPermission()`；代码会检测此接口。
- 未授权、不支持、等待 4.5 秒仍无有效数据，都会有对应提示。
- 页面隐藏时移除监听；读取数据不上传、不存储、不用于分析。
- 系统开启减少动态效果或网站关闭动态效果时，视差不会启动。
- 实机兼容性受浏览器、系统设置和内嵌 WebView 限制，不能承诺所有手机可用。建议在手机系统浏览器中打开，而不是社交应用内置浏览器。
- 不支持的设备仍可完整使用角色页面、收藏和原图鉴赏。

## 本地预览

可以双击 `index.html` 查看基础页面，但本地文件地址不适合测试分享、传感器与浏览器权限。推荐在项目文件夹运行：

```bash
python -m http.server 8080
```

然后在电脑访问 `http://localhost:8080`。手机访问局域网 HTTP 地址通常不能测试重力权限；请以部署后的 HTTPS 地址进行实机验收。

## 发布后验收清单

1. 用手机和电脑打开网站，确认十张图能显示；特别检查含空格、方括号的文件名。
2. 点击所有角色标签，刷新 `#角色ID` 深链接，测试后退。
3. 收藏一个角色，刷新后检查是否保留；通过右上角收藏面板跳转。
4. 打开原图，滑动、切图、放大、保存；按 Esc 或关闭按钮退出。
5. 在手机允许重力权限，倾斜、校准、关闭，并检查拒绝权限时的提示。
6. 试用夜间模式、正文放大、关闭动态效果。
7. 将浏览器文字缩放到 200%，确认可阅读和操作。

## 排错

- **整个站点 404**：检查 Pages 部署状态、分支与根目录，确认根目录有 `index.html`。
- **页面有文字但没有图片**：确认 `assets/` 路径及文件名完全一致；不要使用聊天附件的序号前缀文件名。
- **更新没有马上显示**：等待部署完成后刷新；必要时清理浏览器缓存。本项目没有 Service Worker，不会额外制造离线版本缓存。
- **重力按钮没有效果**：确认 HTTPS、手机感应支持及网站权限，关闭减少动态效果；根据提示重新操作。
- **收藏不持久**：检查是否处于隐私模式，或浏览器是否禁用了本地存储。
- **保存原图变成打开图片**：这是部分手机浏览器行为，可在原图页长按保存。
