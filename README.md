# 晴间来信 2.0 · 二次元角色沉浸收藏册

更新日期：2026-10-04。基于增强版 PRD 升级，仍然是**无需构建、无后端、无 CDN、无 npm 运行依赖**的静态网站。手机优先，同时适配平板和电脑。

本包包含完整源码、十张原图和七段 12 秒的合成音景。所有原图名称与内容保持不变。人物介绍为本站创作设定，汐音、雪澪为暂定名。二次元作品及素材的权利归原权利人。

## 先发布，再在手机上体验

1. 解压 ZIP，打开 `qingjian` 文件夹。
2. 将**文件夹里面的内容**上传到 GitHub 仓库根目录，不要只上传 ZIP，也不要多套一层目录。
3. 仓库根目录应直接显示 `index.html`、`style.css`、`app.js`、`media.js`、`characters.js`、`assets/` 和 `.nojekyll`。
4. 打开 **Settings → Pages**。
5. Source 选择 **Deploy from a branch**，选择上传文件的分支（通常为 `main`）与 **/ (root)**。
6. 保存，等待部署完成，使用 Pages 给出的 HTTPS 地址访问。
7. 在真实手机的系统浏览器中测试感应、录音、分享和触屏手势。

更新旧版时，覆盖以上源码并上传七个 `ambience-*.mp3` 文件即可。原来的收藏和夜间设置会继续使用；新数据会保存在同一网站地址下。换域名或仓库路径会改变浏览器存储归属，不会自动跨网站迁移。

GitHub Pages 官方说明：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 2.0 功能

### 视觉与动画

- 角色档案 3D 翻入、标题缩放、主画面光影闪过。
- 收藏爱心心跳、旋转、粒子与计数反馈；全角色收藏触发彩色烟火。
- 主图前后切换使用相册滑页动画；鉴赏弹窗从点击画面的区域展开，关闭时收回。
- 标签彩色边框、悬停放大、点击向中心收拢，再进入相关角色集合。
- 手记与档案切换时纸张翻起、翻入。
- 角色切换触发 2.5 秒的淡光轨迹。
- 夜间 68 颗星星以不同周期闪烁；档案有可关闭的色彩呼吸。
- 模态背景模糊可调为 0–20px，默认 10px；面板有进出动画。
- 图片读取时有胶片加载层；失败时提示重试或显示不可用状态。
- 粒子数量有上限，动画结束自动移除；页面隐藏时暂停动画和多媒体。

用户关闭动态效果或系统启用 `prefers-reduced-motion` 时，动画、视差和粒子都会禁用，导航与所有基础功能仍可使用。

### 发现与收藏

- 五组可共享的心情标签，点击进入聚合页。
- 搜索结果分为角色、标签、描述；输入即筛选，结果点击后直接导航。
- 小白与小黑互相关联，其他关系为本站创作的故事线索。
- 收藏可放入多个自定义分组；上限 20 组，名称最长 24 字符。
- 电脑可拖动分组标签排序；手机使用分组前移、后移按钮。
- 删除分组不会删除角色收藏；移除收藏会同步移除其分组归属。
- 原图沉浸模式隐藏操作栏；移动鼠标、轻触画面或向上滑动显示操作；关闭按钮始终保留。
- 双角色对比支持独立切图、同步切图、交换两侧和独立纵向滚动。
- 故事时间轴按照创作顺序排列，可以跳到任意角色。
- 全作品网格默认去重显示十张原图，支持角色、主题、标题筛选；先载入六张，再滚动追加。数据有限时不会虚构无限内容。

### 分享、多媒体与手机交互

- Canvas 生成 1080×1440 PNG 角色卡片，包含头像、名字、台词、品牌与网址。
- 支持下载图片、复制角色链接、浏览器系统分享；取消分享不算完成分享。
- 视频使用 Canvas + MediaRecorder 生成五秒动画，720×960，无麦克风和背景音。
- 视频编码由浏览器能力决定，优先 WebM，可用时选择 MP4。**不能保证每台手机都导出 MP4，也不能保证社交平台接受 WebM**。不支持时保留 PNG 和链接分享。
- 可填写推荐者称呼、欢迎导览、主题与来源标记；推荐者是链接中填写的文本，不验证身份。
- 分享链接示例：`?from=朋友&intro=true&theme=follow&shared_theme=night&utm_source=qq#leaf`。
- 来源标记不用于联网分析，没有点击量或分享转化率的服务器统计。
- 读白提供中文、日文、英文台词，语速、音量与声音可调。它是设备语音合成，**不是角色原声**。
- 读白默认筛选本机语音。如果系统没有该语言的本机声音，需要安装系统语音，或自行启用“允许设备网络语音”。网络语音可能由系统/浏览器服务联网处理；本网站不上传故事内容到自建服务。
- 语音日记由用户点击申请麦克风权限，最长两分钟；停止后保存，可再次播放、下载或删除。
- 录音 Blob 保存到 IndexedDB，重新打开页面会生成新的播放 URL；不会把临时 Blob URL 当作持久数据。
- 关闭录音面板或页面隐藏时停止录音并尝试保存，同时关闭麦克风轨道。
- 原图支持双指旋转与缩放、双指轻点切换 200%、向下拖动关闭、向上拖动显示操作栏。已放大的图片优先允许平移，避免切图误触。
- 角色档案上下滑动可收起/展开手记；仍保留明确的按钮操作。
- 故事滑动一屏显示一位角色，向上/向下切换，轻触显示寄语。
- 触屏长按角色入口可打开预览，直接收藏或进入详情。预览保持可操作，点击关闭或外部退出，不在松手时立即消失。
- 卡片浮窗可以拖动改变位置与堆叠，轻触恢复原图；键盘也可选择卡片。
- 3D 卡片库可翻到背面阅读寄语，再打开完整档案。

### 成就与个人进度

八项徽章使用内联 SVG 图标，统计仅属于当前浏览器。

| 徽章 | 解锁条件 |
| --- | --- |
| 绿叶探险家 | 看过小叶子的全部三张作品 |
| 深度收藏者 | 收藏至少五位角色 |
| 午夜守护人 | 本地时间凌晨 0–6 点使用夜间模式 |
| 故事猎人 | 访问全部七位角色 |
| 分享达人 | 完成三个不同角色的系统分享、链接复制或手动复制事件 |
| 今日相遇者 | 连续访问七天 |
| 电影观影者 | 看过全部十张唯一原图 |
| 对比大师 | 进入对比模式五次 |

图片只有在主画面、鉴赏或对比中成功载入时计入已看，不把整个网格里的缩略图自动记为已看。小白、小黑共享一张双人图，因此全站图片总数按唯一文件去重，不使用 PRD 中示例的“70 张”。

收藏册展示相遇角色、收藏角色、原图进度、今天/最近七天/累计阅读时长、连续相遇天数、回看排行、最近十五次相遇。阅读时长在页面可见且最近两分钟有交互时累计，每十五秒保存。连续访问和午夜徽章使用浏览设备的本地日期和时间。

连续七天或收藏五位角色后，显示金色寄语。成就解锁是本地游戏反馈，不授予真实奖品。

### 模拟彩蛋

“虚拟相遇”按时间生成一组演示数字，明确标为本地模拟，不代表真实访客和人气。模拟弹幕默认关闭，开启后使用预设文本，不接收其他用户消息，也不发送消息到服务器。

## 修改或新增角色

编辑 `characters.js` 中的 `window.CHARACTERS`。每个对象至少包含一張图片；`id` 唯一，使用英文、数字或短横线。

```js
{
  id: 'new-character',
  name: '角色名',
  subtitle: '一句话介绍',
  mood: '角色气氛',
  color: '#397dab',
  tint: '#e7f2fb',
  quote: '“一句台词。”',
  story: '包含可探索关键词的手记正文。',
  tags: ['印象标签'],
  details: { '喜欢的事': '具体内容' },
  images: [['原文件名.png', '图片说明']],
  related: ['leaf'],
  themeTags: ['blue-sky'],
  memory: ['关键词'],
  wish: '给浏览者的一句寄语',
  quotes: { 'ja-JP': '日文台词', 'en-US': 'English line.' }
}
```

现有角色的增强字段放在文件末尾的 `characterExtras` 中。新增角色可以直接在对象里填写，或在该映射中添加同名 ID。相关角色 ID 必须存在；主题 ID 来自 `window.THEMES`。

新角色音景文件命名为 `assets/ambience-角色ID.mp3`；不提供时，播放会提示失败，角色页面仍正常。附带音景为自行合成的轻音乐/噪声纹理，不声称是真实环境录音，可以替换为你有权使用的音频。

添加角色或图片后，进度分母与全作品网格自动更新。已有成就解锁记录不会被主动收回。

## 安全与权限

- 用户输入（分组名、搜索、推荐者称呼等）通过转义或 `textContent` 写入，不能作为 HTML 执行。
- 图片路径函数拒绝斜杠和路径段，再用 `encodeURIComponent` 编码文件名；编码本身不是完整的路径访问控制。
- 麦克风只在主动点击录音后请求，录音不上传。
- 重力数据只用于当前画面，不存储、不上传。
- 视频生成不访问麦克风。
- 音频不自动播放；重新打开网站需要点击启用。
- 本机读白默认不调用网络语音；启用网络声音时，行为由设备服务决定。

## 浏览器能力与降级

| 功能 | 条件 / 降级 |
| --- | --- |
| 基础页面、路由、收藏、搜索 | 面向现代 Chrome / Edge / Firefox / Safari；不支持 IE11 |
| 原生 dialog | 支持时使用原生模态；较旧 Safari 提供遮罩、关闭与键盘焦点循环降级 |

| 重力视差 | HTTPS + 感应设备 + 浏览器权限；无数据时提示，不妨碍浏览 |
| 分享与剪贴板 | 系统分享 → 复制链接 → 手动复制 |
| 全屏 | 支持 Fullscreen API 时可用，否则保留沉浸弹窗 |
| 设备读白 | 需要 SpeechSynthesis 与可用声音；无声音时提示安装/选择 |

## 本地预览

在 `qingjian` 文件夹执行：

```bash
python -m http.server 8080
```

电脑打开 `http://localhost:8080`。双击 `index.html` 可以看基础界面，但本地文件模式可能限制动态加载、Canvas 导出、分享与权限。手机用局域网 HTTP 地址通常不能测试感应与录音，使用部署后的 HTTPS 地址验收。

5. 尝试双指旋转/缩放、滑动关闭、故事滑动和长按预览。
6. 用键盘操作角色标签、模态、作品卡片和翻转卡片，检查焦点与 Esc 关闭。
7. 开启系统减少动态效果和夜间模式；检查按钮与文字对比度。
8. 用 Lighthouse/DevTools 测量实际部署地址的性能与帧率，勿直接把 PRD 目标当成测量结果。

## 排错

- **站点 404**：检查 Pages 部署分支、目录和根目录的 `index.html`。
- **页面有文字但图片不显示**：确认 `assets/` 内名称完全一致；不要使用聊天附件的 `01-` 等序号前缀。
- **分享或日记组件加载失败**：确认上传了 `media.js`，而不只是旧版的三个脚本。
- **音景没有声音**：先点击音景，检查音量与七个 MP3 文件；切换后台时会暂停。
- **重力/录音不可用**：检查 HTTPS、系统浏览器与权限，必要时换浏览器。
- **收藏丢失**：检查网站地址是否变化、是否在隐私窗口，或是否清理了网站数据。
- **更新未显示**：等待 Pages 部署完成再刷新；本项目没有 Service Worker 离线缓存。
- **语音声音不出现**：安装本机对应语言语音，或显式允许设备网络声音。
- **无法清除日记**：关闭此站的其他标签页后再清除，避免存储连接被占用。
